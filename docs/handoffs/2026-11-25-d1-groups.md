## Preserved behavior

- Authentication runs before body validation on every route, matching `groupsRouter.use(requireAuth)`.
- Create validates the shared schema, trims the name, de-duplicates IDs case-insensitively, appends the creator and returns `201` with the populated group.
- List returns only groups containing the viewer, ordered by `lastMessageAt` then creation time; detail enforces participant access and returns the exact message count.
- Message send enforces the chat limiter before validation, checks participation, trims the message, updates `lastMessage`/`lastMessageAt`/`updatedAt` atomically with the insert and returns `201`.
- History applies the legacy `skip`/`limit` defaults and caps, sorts newest-first, then reverses the page before returning it.
- Add/remove keep the creator-only guard and legacy validation/error order. No-op add returns the existing group; a re-added participant appends after the highest stored position, matching legacy `$addToSet` after `$pull`. Remove rejects the creator and missing members with the legacy messages.
- Leave deletes the group and its messages when the last participant leaves; otherwise it removes the member and transfers `createdBy` to the first remaining participant.
- DTOs match the disposable MongoDB characterization: raw lean documents include `__v: 0`; populated users contain only `_id`, `name`, `username` and present optional avatar fields; partial `avatarParts` contains only set keys; `lastMessageAt` is omitted until a message is sent.
