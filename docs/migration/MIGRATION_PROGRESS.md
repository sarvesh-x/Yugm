# Migration progress by preservation gate

The [root tracker](../../MIGRATION_PROGRESS.md) remains the work log. The [active 18-phase plan](implementation-plan.md#phase-gates) defines each gate. This index records the current acceptance boundary.

**Active local scope.** `npm run dev` starts the MongoDB-free loopback Worker. D1 covers Auth, Profile and VIP privacy, R2 avatars, player cosmetics, all clan HTTP routes, notifications, room discovery, history and lifecycle controls, LiveKit-compatible token admission, the full Bonds route group with Cron finalization, the full wallet route group with host-neutral payment providers, the game catalog, Profile/social operations, dating, direct conversations, level progression with daily check-in, and the first eleven admin config/audit/support routes. The mount audit found 461 legacy-only patterns, including 19 room and 204 admin routes. [Latest audit](../handoffs/2026-11-25-d1-admin-support.md) · [Journey sequence](implementation-plan.md#journey-order)

**Production checkpoint.** Release builds use the configured production HTTPS origin. The D1 Worker binds hosted `yugm` and the five verified hosted R2 buckets. The versioned D1 schema and reference catalogs are present in both environments. Android RTC, legacy data transfer and the remaining journeys are open. [D1 setup evidence](../handoffs/2026-11-24-d1-schema-and-reference-seed.md) · [Hosted R2 verification](../handoffs/2026-11-24-hosted-r2-d1-endpoint-audit.md)
