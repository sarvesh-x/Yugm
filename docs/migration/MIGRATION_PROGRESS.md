# Migration progress by preservation gate

The [root tracker](../../MIGRATION_PROGRESS.md) remains the work log. The [active 18-phase plan](implementation-plan.md#phase-gates) defines each gate. This index records the current acceptance boundary.

**Active local scope.** `npm run dev` starts the MongoDB-free loopback Worker. D1 covers Auth, Profile and VIP privacy, R2 avatars, player cosmetics, all clan HTTP routes, notifications, room discovery and history, select wallet paths, the game catalog, Profile/social operations, dating preferences and matches, and direct conversations with text sends and replies. The mount audit found 526 legacy-only patterns, including room lifecycle, Bonds, payment operations and admin. [Latest audit](../handoffs/2026-11-24-mongodb-runtime-cutover.md) · [Journey sequence](implementation-plan.md#journey-order)

**Production checkpoint.** Release builds use the configured production HTTPS origin. The D1 Worker binds hosted `yugm` and the five verified hosted R2 buckets. The versioned D1 schema and reference catalogs are present in both environments. Android RTC, legacy data transfer and the remaining journeys are open.
