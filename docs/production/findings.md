## Additional investigation, not closed findings

- DM `mediaUrl` is caller supplied (`routes/users.ts:1055`); trace ownership/readiness and private download authorization before defining media policy. Ordinary public assets and private chat attachments require different policies.
- Edit/reaction block semantics differ from send/history. Decide whether existing-message actions after a block should remain allowed, then test all transports.
- Bundled Mongo Compose has no replica set initialization; production Mongo topology, indexes, duplicate history, negative balances, orphan media and actual financial divergence are unknown.
- Startup `ensureProductionIndexes` drops a legacy purchase index then creates declared indexes. Rehearse on sanitized data before treating it as safe online migration.
- No existing tests inspected prove database transaction rollback, replay races, call ownership, event oversell, restore, or provider reconciliation. Passing schema/arithmetic tests cannot close these findings.
